# academy
Comprehensive Academy Management System for gyms and martial arts schools. Features student enrollment, attendance tracking, rank/belt progression, membership plans, and financial management.

## Tech Stack
- Java 21 (LTS)
- Spring Boot 3.5.x
- PostgreSQL 18
- Docker / Docker Compose
- Maven

## Como executar localmente

### Pré-requisitos
- JDK 21
- Docker

### Passos
```bash
git clone ...
cd academy
docker compose up -d
./mvnw spring-boot:run
```
